About

Software Test Engineer focused on quality engineering, test automation, and scalable testing systems for modern web and mobile products.

Currently at Ecosia, where I design and maintain automated testing frameworks using Selenium WebDriver, Playwright, Cypress, and Nightwatch.js — integrated into CI/CD pipelines via GitHub Actions and CircleCI to support reliable, fast releases for millions of users.

My experience spans test automation strategy, QA engineering, regression testing, API testing, and end-to-end validation across distributed systems. I work closely with product managers, designers, and developers to ensure features are testable, reliable, and production-ready throughout the software development lifecycle.

I actively explore AI-assisted software development and testing, using tools like GitHub Copilot, OpenAI models, and Cursor to improve debugging, test generation, and engineering productivity.
